### Запуск завданнь

Для початку потрібно склонувати проєкт.

Для того щоб його запустити необхідна Node V18+, NPM V10+

#### Команди для запуску

```
$ npm run build
$ npm start
```

Далі потрібно вписати цифру яка відповідає необхідній роботі, написати її в терміналі і натиснути Enter.
