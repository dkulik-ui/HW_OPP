# Task 2 - Визначте загальні форми (синтаксис) оператора-функції члена класу та дружньої функції-оператора.

## Пояснення 

### Оператор-функція визначається як метод класу. Вона викликається для об’єктів цього класу і має доступ до всіх його членів. Така функція дозволяє переназначати поведінку стандартних операторів для об’єктів користувацьких типів.

### У TypeScript переназначення операторів немає, тому аналогом оператор-функції є метод класу, який виконує таку ж дію. Наприклад:

![proofOne](./data/_media/Screenshot%202025-12-11%20at%2020.39.58.png)

### Дружня функція-оператор не є методом класу, але проголошується другом за допомогою ключового слова friend. Це надає їй доступ до приватних і захищених членів класу

### У TypeScript механізму friend немає, але подібну поведінку можна відтворити за допомогою статичного методу.
