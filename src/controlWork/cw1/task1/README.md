# Task 1 - Проаналізуйте особливості вказівників на базові та похідні класи.

## Пояснення 

### Вказівник базового класу може вказувати на об’єкт похідного класу, але матиме доступ лише до членів базового класу.

![proofOne](./data/_media/Screenshot%202025-12-11%20at%2019.46.50.png)

### Вказівник похідного класу не може вказувати на об’єкт базового класу, бо там немає всіх необхідних членів.

![proofTwo](./data/_media/Screenshot%202025-12-11%20at%2019.58.06.png)

### Приведення від похідного до базового — безпечне, але від базового до похідного — небезпечне, потребує cast.

![proofThree](./data/_media/Screenshot%202025-12-11%20at%2020.09.54.png)

### Віртуальні методи дозволяють викликати методи похідних класів через вказівник на базовий клас.

![proofFour](./data/_media/Screenshot%202025-12-11%20at%2020.10.04.png)
